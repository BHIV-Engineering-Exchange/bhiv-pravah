1. Initialize and build:
go mod tidy
go build -o sarathi-pdp.exe sarathi_pdp_core.go pdp_engine.go policy_store.go registry_interface.go clock.go


2. First run — creates decision_trace.json:
.\sarathi-pdp.exe


3. Second run — APPENDS to decision_trace.json (you'll see "Loaded X existing trace entries"):
.\sarathi-pdp.exe


4. Replay check (separate command):
go run replay_check.go pdp_engine.go policy_store.go registry_interface.go clock.go

# BHIV Command Center Design System — Typography

We enforce strict visual hierarchy using sans-serif fonts (e.g. Inter, Outfit, or system-ui) optimized for high legibility under pressure.

## Font Sizes & Weights

### Headers
- **h1**: `text-4xl` (36px / 2.25rem), `font-black`, letter spacing: `tracking-tight` (Main Dashboard Headers, Verdicts)
- **h2**: `text-2xl` (24px / 1.5rem), `font-bold` (Card titles, section headers)
- **h3**: `text-lg` (18px / 1.125rem), `font-extrabold` (Block headers, modal titles)

### Body & Data
- **body-large**: `text-base` (16px / 1.0rem), `font-normal` (Main descriptors)
- **body-regular**: `text-sm` (14px / 0.875rem), `font-semibold` / `font-medium` (Metrics descriptions, metadata labels)
- **caption**: `text-xs` (12px / 0.75rem), `font-bold` uppercase, `tracking-wider` (Stat title labels, badge texts)

### Technical / Log Output
- **code-large**: `text-sm` (14px / 0.875rem), `font-mono` (Trace IDs, commit hashes)
- **code-regular**: `text-xs` (12px / 0.75rem), `font-mono` (JSON responses, API structures, evidence logs)

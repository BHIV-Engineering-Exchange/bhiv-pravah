# BHIV Command Center Design System — Colors

We enforce a high-contrast, premium, dark-first and clean light-first aesthetic tailored for rapid operational review and command-center visibility.

## Color Tokens

### Slate Base (Slate / Neutral Scale)
- **slate-50**: `#f8fafc` (Page Background Light)
- **slate-100**: `#f1f5f9` (Card/Block Background Light)
- **slate-200**: `#e2e8f0` (Border/Divider Light)
- **slate-500**: `#64748b` (Muted Label Text)
- **slate-700**: `#334155` (Subtle Borders Dark / Text Light)
- **slate-800**: `#1e293b` (Card Background Dark)
- **slate-900**: `#0f172a` (Page Background Dark)
- **slate-950**: `#020617` (Deep Background Accent)

### State Indicator Colors (Operational Verdicts)
- **emerald-500**: `#10b981` (PASS / READY / COMPLETED)
- **rose-500**: `#f43f5e` (FAIL / HIGH RISK / REJECTED)
- **amber-500**: `#f59e0b` (NEEDS WORK / BORDERLINE / MEDIUM RISK)
- **blue-500**: `#3b82f6` (REINFORCEMENT / ADVANCEMENT / INFO)

### Accents & Gradients
- **Primary Gradient**: `from-blue-600 to-indigo-700` (Main Actions, Hero Badges)
- **Success Gradient**: `from-emerald-500 to-teal-600`
- **Failure Gradient**: `from-rose-500 to-red-600`
- **Warning Gradient**: `from-amber-500 to-orange-600`

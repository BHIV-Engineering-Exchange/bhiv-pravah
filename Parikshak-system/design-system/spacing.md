# BHIV Command Center Design System — Spacing

We use an 8px (0.5rem) grid system to maintain absolute mathematical proportion and visual alignment across high density operational displays.

## Spacing Scales

| Token | Size (px) | Size (rem) | Usage |
|-------|-----------|------------|-------|
| `space-1` | 4px | 0.25rem | Internal button padding, tiny offsets |
| `space-2` | 8px | 0.5rem | Micro-gaps between related parameters, inner badges |
| `space-3` | 12px | 0.75rem | Inner padding of small metrics/evidence labels |
| `space-4` | 16px | 1.0rem | Standard gap between minor indicators, block margins |
| `space-6` | 24px | 1.5rem | Standard card padding, grid gaps for layout components |
| `space-8` | 32px | 2.0rem | Grid sections margins, page-level headers spacing |
| `space-12` | 48px | 3.0rem | Major layout partitions |
